#  查询数据表的命令

## PostgreSQL（技能相关表）

### 查看三张表是否存在
```bash
docker exec -it postgres psql -U root -d postgres -c "\\dt public.mcp_tool_semantic public.mcp_tool_vector public.skill_vector_snapshot"
```

### 查看三张表字段定义
```bash
docker exec -it postgres psql -U root -d postgres -c "SELECT table_name,column_name,data_type,is_nullable,column_default FROM information_schema.columns WHERE table_schema='public' AND table_name IN ('mcp_tool_semantic','mcp_tool_vector','skill_vector_snapshot') ORDER BY table_name,ordinal_position;"
```

## MySQL（XXL-Job 相关表）

### 查看 xxl_job 库中的表
```bash
docker exec -it mysql mysql -uroot -p123456 -D xxl_job -e "SHOW TABLES LIKE 'xxl_job_%';"
```

### 查看关键表字段（示例）
```bash
docker exec -it mysql mysql -uroot -p123456 -D xxl_job -e "SHOW COLUMNS FROM xxl_job_lock; SHOW COLUMNS FROM xxl_job_log;"
```

## 查看 xxl-job 容器日志（tail）

### 查看最近 100 行日志
```bash
docker logs --tail 100 xxl-job-admin
```

### 持续跟踪最新日志
```bash
docker logs -f --tail 100 xxl-job-admin
```

### 只看错误相关日志
```bash
docker logs --tail 500 xxl-job-admin 2>&1 | grep -Ei "error|exception|fail|timeout|refused"
```
